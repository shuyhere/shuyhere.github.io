# shuyhere.github.io

Personal academic homepage of Shu Yang, served by GitHub Pages at <https://shuyhere.github.io>.

Plain HTML and CSS, no build step.

- `index.html` — homepage (about, news, publications, blog list, services, talks, visiting)
- `style.css` — all styling, with automatic dark mode
- `blog/*.html` — blog posts; add a new post by copying an existing file and linking it from the Blog section of `index.html`
- `assets/` — avatar and cover image

To update: edit the files, commit, push to `main`. GitHub Pages redeploys within a minute.
